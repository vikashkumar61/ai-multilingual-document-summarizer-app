AI MULTILINGUAL DOCUMENT SUMMARIZER - QUICK START

1. Extract the entire ZIP into a normal folder (do not run it inside the ZIP).
2. Install Python 3.12 if it is not installed. During setup enable Add Python to PATH.
3. Double-click START_LOCALHOST.bat.
4. Wait for packages to install and Streamlit to start.
5. Open http://localhost:8501 in Chrome.
6. Upload a PDF, DOCX, or TXT file and click Generate Summary. A fast offline summary is the default.
7. To try the multilingual mT5 model, tick 'Try Transformer AI model' in the sidebar before generating.

IMPORTANT
- Keep the black terminal window open while using the app.
- First installation can take several minutes and needs internet access.
- First AI summary may download the mT5 model and take additional time.
- The fast offline extractive summary appears by default, so you get a result without waiting for model loading. If you enable the AI model and it fails, the offline summary remains available.
- Scanned/image-only PDFs need OCR and are not supported in this version.
- Stop the app with Ctrl+C in the terminal window.

If setup fails, take a screenshot of the last red error in the terminal.
